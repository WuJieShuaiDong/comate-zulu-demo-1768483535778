## ✅ 核心功能实现

### 1. 赚钱效应评分 (0-100分)

**算法公式**:
```
总分 = 连板梯队分(40) + 板块集中度(20) + 龙头溢价(20) + 情绪持续性(20)

连板梯队分 = (5板数×10 + 3板数×5 + 2板数×2) / 涨停总数 × 4
板块集中度 = 前3板块涨停数 / 总涨停数 × 40
龙头溢价 = (龙一涨幅 / 平均涨幅 - 1) × 10
情绪持续性 = 涨停数 / (涨停数 + 跌停数) × 25
```

**情绪等级**:
- `STRONG` (≥70分): 主升浪，可主动建仓
- `MODERATE` (40-69分): 震荡期，小仓位试错
- `WEAK` (<40分): 退潮期，空仓观望

---

### 2. 龙头股识别

**三阶段识别逻辑**:

| 阶段 | 连板数 | 核心指标 | 评分标准 |
|------|--------|----------|----------|
| 首板龙 | 1板 | 换手率15-30% + 流通盘<50亿 | 基础分50 |
| 2-3板龙 | 2-3板 | 早盘封板 + 板块共振>3只 | 基础分60 |
| 高度板 | >3板 | 连板高度 + 妖股基因 | 每板+15分 |

**输出格式**:
```python
{
    'symbol': '300xxx',
    'name': 'XX科技',
    'board_count': 3,
    'score': 85,
    'reasons': ['早盘封板 09:35:00', '板块共振 5只'],
    'sector': '人工智能'
}
```

---

### 3. 板块持续性判断

**判断标准**:
- `HIGH`: 涨幅>3% + 涨停数>2 → ✅ 可追涨
- `MEDIUM`: 涨幅>1% → ⚠️ 观察
- `LOW`: 涨幅≤1% → ❌ 回避
